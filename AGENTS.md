# Working in this repo

A bilingual (Arabic RTL / English LTR) site for Naranj, the Damascene
restaurant on Straight Street. Next.js 16 App Router, React 19, Tailwind v4.

See [README.md](README.md) for setup, structure and data provenance.

## The one rule that matters most

**Every fact and every photograph on this site comes from the restaurant's own
channels.** Nothing is invented and presented as official — no made-up awards,
no imagined branch lists, no stock or generated imagery.

If you add content, add it with a `SOURCE:` comment naming where it came from,
the way the existing entries in `content/` do. If a fact cannot be sourced,
either leave it out or mark it clearly as pending the owner's input (see the
"Needs real data" list in the README). Menu names and prices in
`content/menu.ts` are explicitly flagged as a placeholder structure.

## Conventions

**Colour.** Components never name a raw colour or a hex value. They use the
palette scale — `ink-*` (surfaces), `brass-*` (the brand gold), `stone-*` and
`ivory-*` (text) — and each step resolves to a CSS variable that
`app/globals.css` redefines for the light theme. This is what lets the theme
flip without touching a component. Keep it that way: a hardcoded colour is a
bug, because it will not flip.

After touching the palette, run the audit. It reads the real values out of
`globals.css` and derives the token list from actual `text-*` usage, so it
cannot drift:

```bash
node scripts/check-contrast.js
```

Every text/surface pairing must clear 4.5:1 in both themes.

**Bidirectionality.** Use logical properties (`ms-`/`me-`, `ps-`/`pe-`,
`start-`/`end-`, `text-start`), never `left`/`right`. Arabic does not take
uppercase or wide letter-spacing — the `tracking-luxe` utility already
neutralises itself under `html[lang="ar"]`, and buttons carry
`rtl:normal-case`. Directional glyphs get `flip-rtl`.

**Language.** All user-facing strings live in `lib/i18n/dictionaries.ts`. The
Arabic object is the source of truth; `Dictionary` is derived from it, so
TypeScript fails the build if the English one drifts out of shape. Never put a
literal string in a component.

**Images.** Real photographs only. `SmartImage` fades one in while it decodes
and never substitutes decorative filler — a dish with no photograph is set
typographically instead (see `dish-card.tsx`). Originals stay in
`public/images/src/`, which is gitignored; the shipped files are generated by
the scripts in `scripts/`.

**Motion.** Scroll reveals are Framer Motion and carry `data-reveal`, which a
`<noscript>` rule in the locale layout forces visible. Anything that hides
content until an animation runs needs that attribute.

## Before you call it done

```bash
npx tsc --noEmit
npm run build
node scripts/check-contrast.js
```
